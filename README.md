Forecasts Grand Theft Auto VI's launch-day Twitch viewers, hour by hour, from the first hour's count. The program fits its forecast at run time from 37 past game launches in the case file (k-nearest neighbours + log-regression on hour-1 size), and writes five quantiles for hours 2-24. Backtest (leave-one-out over the 37 launches): mean pinball loss 0.3935 vs 0.9297 for the house baseline.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
